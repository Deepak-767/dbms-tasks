## Technology
- MySQL 8.0+
- Relational database design
- Primary and foreign keys
- CHECK, UNIQUE and ENUM constraints
- INSERT, UPDATE and DELETE operations
- JOIN, GROUP BY, aggregate functions and CASE expressions

## Notes
Each task has its own database so that the SQL can be executed independently without destroying another task's tables.

Task 1–5 are based on the existing e-commerce DBMS work inspected from the source project and have been cleaned up for consistency. Task 6 was added as the final review/rating module because no explicit Task 6 file was present in that source project.
