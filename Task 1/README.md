# Task 1 – Requirement Analysis and Customer Database

## Objective
Define the core requirements for an e-commerce customer module and implement a normalized customer database.

## Database
`task1_customer_db`

## Main concepts
- Customer master data
- Unique email constraint
- Customer status
- Basic reporting and update operations

## How to run
Run `Task1_Customer_Database.sql` in MySQL 8.0+.
