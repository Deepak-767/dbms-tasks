# Task 2 – Product and Category Database

## Objective
Create a product catalogue using categories, primary keys, foreign keys, constraints, CRUD operations and summary reports.

## Database
`task2_product_db`

## Included
- Categories and products
- One-to-many category/product relationship
- Price and stock management
- Category summary and low-stock reports

## How to run
Run `Task2_Product_Category.sql` in MySQL 8.0+.
