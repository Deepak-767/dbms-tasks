# Task 3 – Seller and Inventory Management

## Objective
Extend the product catalogue with sellers and inventory records using foreign keys and inventory reporting.

## Database
`task3_inventory_db`

## Included
- Categories, products and sellers
- Seller-to-inventory and product-to-inventory relationships
- SKU, unit price, stock and reorder level
- Available, low-stock and unavailable reports
- Seller-wise and category-wise summaries

## How to run
Run `Task3_Seller_Inventory.sql` in MySQL 8.0+.
