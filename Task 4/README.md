# Task 4 – Order Management System

## Objective
Implement customers, products, orders and order details with referential integrity and order reporting.

## Database
`task4_order_db`

## Included
- Customer and product master tables
- Orders and order details
- Order status management
- Customer order history
- Customer-wise and product-wise reports
- Referential integrity with foreign keys

## Data quality
Order detail prices match the product catalogue so order totals are consistent.

## How to run
Run `Task4_Order_Management.sql` in MySQL 8.0+.
