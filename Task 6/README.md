# Task 6 – Product Review and Rating Management

## Objective
Complete the e-commerce database workflow with customer reviews and product ratings using keys, constraints, aggregation and reporting.

## Database
`task6_review_db`

## Included
- Customers and products
- Product reviews and ratings
- One review per customer per product
- Rating validation from 1 to 5
- Average rating and review-count reports
- Highly rated and low-rated product reports
- Review update operation

## Assumption
No Task 6 specification file was present in the inspected source repository, so this task is implemented as the final review/rating module of the same e-commerce theme.

## How to run
Run `Task6_Product_Review_Rating.sql` in MySQL 8.0+.
